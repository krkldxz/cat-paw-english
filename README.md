# 英语背诵与学习软件（cat paw）

**端侧离线 AI · 把课文和试卷变成"只属于你的"背诵清单**

粘贴文本 / 📷 拍照 / 📄 传 PDF，本机大模型自动提炼 **生词 · 词组 · 作文金句 · 搭配 · 语法**，
按 **考纲 × CEFR × 历史掌握** 三层过滤生成背诵清单，再用 **默写 + SM-2 间隔复习** 闭环到长期记忆。

**全程离线运行，学习数据不出机器。** 无需联网、无需 API Key、无调用费用。

`AGPL-3.0` · `Node.js 零依赖后端` · `llama.cpp 端侧推理` · `Gemma 4 (Apache-2.0)`

## 运行前提与首次启动

| 需要什么 | 说明 |
|---|---|
| **Node.js 18+** | 唯一必需项。项目**零 npm 依赖**，不需要 `npm install` |

| Python 3（可选） | 仅用于照片 OCR 与 PDF/Word 解析；没有 Python 时这两项降级，**粘贴文本与视觉模型不受影响** |
| 显卡（可选） | NVIDIA 显存 ≥ 4.5 GB 自动 GPU 加速；无显卡走 CPU 层（较慢，功能完整） |
| 磁盘 / 内存 | 完整体验约 5.3 GB（AI）+ 仓库 38 MB；内存 8 GB 以上 |

**首次启动流程**：双击 `启动背诵工具.bat` → 自动检查 Node / 引擎 / 模型 →
若缺少 AI，会提示三选一：**① 现在自动下载**（推荐）· **② 先不下载，以最小版启动**（界面 / 词书 / 默写 / 记忆可用）· **③ 退出**。
下载完成后自动拉起引擎与网页服务并打开浏览器。

## 它和常见的背单词 App 有什么不同

| | 云 API 类背单词 App | 通用 AI 套壳工具 | **本项目** |
|---|---|---|---|
| 数据去向 | 上传到厂商服务器 | 上传到模型厂商 | **不出本机** |
| 离线可用 | ✗ | ✗ | **✓**（引擎+模型全本地） |
| 费用 | 订阅 / 按量 | 按 token 计费 | **0** |
| 清单来源 | 平台预设词表 | 模型自由发挥 | **你的课文 → 本机模型提炼 → 规则层复核** |
| 分层依据 | 词表难度 | 无 | **考纲词书 × CEFR 等级 × 你的历史掌握** |
| 输出可解释 | 弱 | 弱 | **每个词带：归属（考纲/拓展）、CEFR 级别、文中义 vs 全义** |
| 记忆闭环 | 有 | 通常无 | **默写 + SM-2 排程 + 掌握三分 + 错题池**（开源可复用） |

> 设计取向是 **"宁多勿少，精简交给学习行为"**：软件不替你拍板"这个词你该会"，而是把有学习价值的词都拉出来，靠你点 ✓/✗ 和默写结果收敛。

## 核心能力

- **三种输入**：粘贴文本 / 📷 拍照（RapidOCR 快路径 ~1-2 秒，质量不足自动切内置视觉模型）/ 📄 PDF·Word（扫描版逐页识别）；长文自动分段合并
- **五板块提炼**：生词 / 词组 / 作文金句 / 搭配 / 语法——本地模型结构化输出，生词带语境义
- **三层过滤**：① 考纲词书（归属）② CEFR 分级 + 年级门槛 ③ 历史掌握状态；**熟词僻义**自动识别并保留
- **候选自评**：候选词默认不显示中文，凭语境判断 ✓认识 / ✗不认识，选择后揭示词义；连续 3 次认识自动折叠
- **默写**：中→英（自动判卷，容错词形变化）/ 英→中（AI 容错批改）；题目含原文例句挖空
- **记忆层**：掌握三分（✅已掌握 / 🔶掌握中 / 🚫未遇见）+ **SM-2 间隔复习**（1→6→15→38→95 天）+ 错题池 + 每日自测（≤30 题）
- **词书系统**：自带 5 套；**可导入自有词书**（JSON 词书或纯文本词表）；**可一键切换主词书**（决定"考纲层"与掌握进度）
- **一键启动**：`启动背诵工具.bat`（Windows）/ `启动(双击我-Mac).command`（macOS），自带显存检测，不足时自动降级

```
                      └────────────────────────────────────────────────────────────────────┘
```

**技术选型说明**

- **为什么端侧模型而非调云 API**：目标场景是学生日常学习，隐私与"随时能用（断网/校园网受限）"是硬需求；Gemma 4 已改为 Apache-2.0，商业与再分发无阻碍
- **为什么 llama.cpp 而非 Ollama**：llama.cpp 可直接带 `mmproj` 做多模态（图片识别），且能塞进单文件夹一体化分发；Ollama 作为可选回退路径保留
- **为什么 Node 零依赖后端**：不需要 `npm install`，clone 下来就能跑——"陌生人 5 分钟能用"优先
- **为什么词书过滤用规则而非模型**："这个词是不是考纲词"必须确定性、可复现；模型只负责语言理解部分
- **词书数据可复现**：所有词书都由 `scripts/` 下的构建脚本从公开数据源重建（见下）

## 快速开始

```bash
git clone <this-repo> && cd english-study
```

1. **取模型与引擎**（约 5.2 GB，一次性）

```powershell
# Windows
powershell -ExecutionPolicy Bypass -File tools\fetch-engine.ps1   # llama.cpp 引擎（无 N 卡加 -Flavor cpu）
powershell -ExecutionPolicy Bypass -File tools\fetch-models.ps1   # 两个 GGUF（断点续传 + sha256 校验）
```

```bash
# macOS / Linux
bash tools/fetch-models.sh
```

2. **启动**：双击 `启动背诵工具.bat`（Windows）/ `启动(双击我-Mac).command`（macOS）· 或最小启动 `node app/server.js`

3. **打开** http://127.0.0.1:8804

> 没有模型也能启动：界面、词书、默写、记忆层全部可用，只有 AI 提炼功能需要引擎。
> 嫌模型大可以用 **Ollama 路径**（文本功能，图片识别降级）——详见 **[快速开始.md](快速开始.md)**。

完整要求、Ollama 备选路径、故障排查 → **[快速开始.md](快速开始.md)**

## 词书

| 词书 | 词量 | 来源 | 许可 |
|---|---|---|---|
| 高考英语核心词表（全国） | 3837 | [tealun/moread-content](https://github.com/tealun/moread-content) + ECDICT 聚合 | MIT |
| 中考英语核心词表（全国） | 1600 | 同上 | MIT |
| 大学英语四级 / 六级 | 5183 / 5974 | 同上 | MIT |
| CEFR 分级词表 | 7035 词头 A1–C2 | [Maximax67/Words-CEFR-Dataset](https://github.com/Maximax67/Words-CEFR-Dataset) | MIT |

- 释义 / 音标 / 词性 / 词频 由 [ECDICT](https://github.com/skywind3000/ECDICT)（MIT）聚合
- **交叉校验**：高考表与 ECDICT 自带 `gk` 考试标签（3677 词）重合 **3662 词 = 95.4%**——两份独立开源数据互相印证，词表可信度可复现
- **导入自有词书**：侧栏「＋ 添加词书」，支持 JSON 词书或纯文本词表（每行一词，制表符/多空格/冒号分隔释义）
- **切换主词书**：主词书决定"考纲层"（归属标记）与掌握进度条

> ⚠️ 各地官方考纲词汇手册多为出版社出版物，**版权原因不随本仓库分发**。需要时请自备原件，用「添加词书」导入。
