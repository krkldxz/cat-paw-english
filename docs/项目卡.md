## 简介
AI 英语背诵清单工具: 学生/老师上传电子或照片英语文本 → 软件内置的开源可商用大模型(本地推理)按年级水平分层提炼 → 生成背诵清单(生词/词组/作文金句/搭配/语法) → 学生挑选板块默写。内置各省市词书, 定向服务。

## 主链路
```
文本输入(粘贴/上传/照片OCR) → AI分层提炼 → 背诵清单 → 选板块默写
```

## 板块
生词(对照课标过滤) / 词组 / 作文金句 / 搭配 / 语法

## MVP 里程碑
- [ ] M1 粘贴/上传文本 → 内置模型结构化提取(JSON) → 清单展示
- [ ] M2 默写交互(释义→拼写), 自评 + AI 判卷容错
- [ ] M3 照片输入 (本地 RapidOCR)
- [ ] M4 词书库: 教材词表 + 各省考纲词表结构化入库
- [ ] M5 老师端(建班/布置/统计) — 二期
