## 一、作品概述

本项目是一款**面向中学生英语学习的端侧离线 AI 工具**。学生把手上任何英语材料（课文、试卷、外刊文章；打字、拍照、PDF/Word 均可）交给它，由**本机运行的大模型**结合语境提炼出生词、词组、作文金句、搭配与语法点，再按"考纲词书 × CEFR 等级 × 个人历史掌握"三层过滤，形成个性化背诵清单；随后通过**双向默写 + SM-2 间隔复习**闭环到长期记忆。全程离线，学习数据不出机器。

**一句话价值主张**：把老师"一对多"的考纲提炼，变成学生随时可自助的"一对一"；把原本 30 分钟级的手工整理，压缩到 20 秒。

## 二、选题背景与需求分析

### 2.1 评价导向已转向"用语言解决问题"

| 层面 | 依据 | 关键表述 |
|---|---|---|
| 课程 | 《义务教育英语课程标准（2022 年版）》 | 目标为**语言能力、文化意识、思维品质、学习能力**四方面核心素养；内容以**主题为引领**、含**语篇**要素；要求"在**体验中学习、在实践中运用、在迁移中创新**" |
| 课程 | 《普通高中英语课程标准（2017 年版 2020 年修订）》 | 课程目标从"综合语言运用能力"转向**学科核心素养**；"语言能力"定义为"**在社会情境中**……理解和表达意义的能力" |
| 评价 | 《中国高考评价体系》（教育部考试中心） | "四翼"含**应用性**（强调**学以致用**）；首创把**"情境"作为考查载体**——"在真实的背景下……解决实际问题" |
| 题型 | 《2020 年全国高考命题评析》 | 英语科"**推出读后续写题型**，将'阅读'与'写作'深度结合"；减少完形、取消短文改错、**增加阅读与写作分值** |
| 地方 | 上海市教委（2025 届春考起） | "听力理解"从笔试**分离并入听说测试机考**（笔试 140→115 分，听说 10→35 分）；官方定性为"**对学生英语实际应用能力的考察**" |

**结论**：考察重心已不是"认不认识这个词、记不记得这条释义"，而是**能否在真实语境中理解并表达**。

### 2.2 现有工具的缺口

主流英语学习 App 普遍采用"词表 → 卡片记忆 → 间隔重复 → 游戏化打卡"模式，优化目标是"记住更多单词"，但存在两个缺口：

1. **只注重单词记忆，不注重运用**——训练的是"词—义"连线，而考试考察的是"语境 → 意义 → 表达"的完整链条；一词多义与熟词僻义尤其吃亏。
2. **缺乏定制化语境**——提供的是通用词表，而非与学生正在面对的材料、日常生活、自身经历绑定的语境。

### 2.3 学校已在做的"提炼"及其边界（本项目的直接切入点）

学校普遍采用"英语提炼"帮助记单词：老师针对卷子与考题提炼单词、词组与考点。方法有效，但边界明确：

| | 学校的提炼 | 学生自己刷题 / 阅读时 |
|---|---|---|
| 谁做提炼 | 老师（专业、有经验） | **没有人**——只能自己查、凭感觉判断 |
| 面向谁 | **面向大众**：照顾不同层次，取舍偏共性 | 本应**面向我自己**：只看未掌握的 |
| 覆盖材料 | 老师选定并讲解的材料 | **学生手上任何材料** |

**核心矛盾**：老师的提炼是"一对多"的，学生自主学习需要"一对一"的——但一对一的成本，老师付不起。

### 2.4 目标用户

主要用户为**初高中学生**（课后自学、考前复习、兴趣阅读）；次要用户为**教师与家长**（当前版本以学生自学为设计中心，教师端功能未实现，见 §7）。

## 三、总体方案

### 3.1 方案主线

```
输入（粘贴 / 拍照 / PDF·Word）
   → 端侧 LLM 结合语境的结构化提炼（五板块）
   → 规则引擎三层过滤（考纲词书 × CEFR × 历史掌握）+ 熟词僻义识别
   → 候选自评（学生自检，不看答案判断）
   → 双向默写（AI 容错判卷 + 原文例句挖空）
   → SM-2 间隔复习 + 掌握三分 + 每日自测（≤30 题）
```

### 3.2 关键技术选型

| 决策 | 选择 | 理由 |
|---|---|---|
| 模型部署 | **端侧推理**（Gemma 4 E2B，Apache-2.0 + llama.cpp） | 隐私（作文/试卷不外传）、断网可用、零调用费用；实测 13–15 秒/篇 |
| 归属判定 | **规则层**而非模型 | 全文词与主词书机械比对，结果确定、可解释、可复核；避免模型"看着像就归类" |
| 作业分层 | 考纲 × CEFR × 历史掌握 三层 + 熟词僻义 | 对应"课内/拓展"的真实需求；熟词僻义是同类工具普遍漏掉的一类考点 |
| 记忆算法 | SM-2 间隔复习 + 掌握三分 | 成熟、可解释、无需训练数据；答错重置、答对指数放宽 |
| 交付形态 | **封装桌面软件**（内置运行时与模型） | 让不写代码的老师与学生能直接用；源码同步以 AGPL-3.0 开源 |
| 数据来源 | 公开许可数据集重建词书（MIT 来源）+ 用户自备导入 | 版权干净；官方考纲手册不随软件分发 |

### 3.3 覆盖范围（明确边界）

- **覆盖**：提炼 · 词书 · 候选自评 · 默写判卷 · 记忆复习 · 阅读 · 聊天（语伴纠错、作文批改）
- **不覆盖**：**听力**（本轮未做）；教师端班级管理（未实现）；移动端（未开始）

## 四、可行性与验证

### 5.1 技术可行性（均为本机实测）

| 指标 | 实测值 |
|---|---|
| 引擎冷启动 | 8 秒 |
| 文本提炼（约 90 词短文） | 13–15 秒 |
| 图片识别 | 13.9 秒 |
| PDF 词汇手册解析（87 页） | 4.6 秒 → 3311 词 |
| 引擎显存占用 | 约 2.9 GB（不足自动降级 GPU 层数） |

### 5.2 数据可行性

词书全部由脚本从**明确许可的公开数据源**重建，并与独立数据源 ECDICT **交叉验证重合 95.4%**；与手工核对版本比对覆盖率 **99.2%**。官方考纲手册因版权不随软件分发，改由用户导入自备原件（PDF 直接可导）。

### 5.3 使用可行性

- **零环境依赖**：封装版内置运行时与模型，双击即用、无需账号、无需联网
- **渐进可用**：素材集未就绪时，仓库克隆即可启动"最小版"（界面 / 词书 / 默写 / 记忆全部可用），AI 功能待首次启动下载完成后自动启用

### 5.4 开源可行性

代码 **AGPL-3.0**：他人分发衍生作品或提供网络服务须同样开源，防止闭源商用；作者保留双授权权利与名称/标识权利。

## 五、风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 端侧模型能力弱于云模型 | 提炼质量 | 用**规则层**承担归属判定与分层（确定性），模型只做语言理解；输出走健壮解析与自动重试 |
| 图片/PDF 版式复杂（双栏、扫描件） | 识别质量下降 | 内置乱码检测与头尾修补、自动重试；扫描件明确提示改用拍照；已知限制如实标注 |
| 隐私与合规 | 学校不敢用 | 全程离线、服务仅监听本机、无上传路径；数据不出机器 |
| 版权风险（词书来源） | 合规红线 | 官方考纲手册不随仓库/软件分发；词书来自 MIT 许可数据源；提供用户自备导入能力 |
| 维护可持续性 | 长期质量 | 全部构建脚本入库可复现；两条回归测试（20 项 + 18 项）；文档体系齐全 |

## 六、创新点（对比式）

1. **把老师"一对多"的提炼变成学生可自助的"一对一"**——已有方案是学校提炼（面向大众、限于老师选定材料）与通用词表；本项目用端侧模型把同等质量的语境化提炼交给学生本人：材料任意、分层按己、定位自助自检。
2. **端侧推理**——数据不出机器、断网可用、零调用费用；对学校而言这是"敢用"的前提。
3. **分层可解释、数据可复现**——归属判定交规则层；CEFR + 年级门槛 + 熟词僻义；词书与独立数据源交叉验证 95.4%。
4. **除听力外的完整闭环且开源可复用**——提炼 → 自评 → 默写（AI 容错判卷、例句挖空）→ 错题池 → SM-2 → 每日自测，另含阅读与聊天（语伴纠错、作文批改）。
5. **用兴趣换内驱力**——学生自选感兴趣题材作为阅读材料，同一套机制照常运转。
6. **封装交付**——内置运行时与模型，不写代码的人也能直接用。
